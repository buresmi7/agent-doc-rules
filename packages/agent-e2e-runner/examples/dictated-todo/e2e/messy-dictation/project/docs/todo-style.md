# Todo Style

Keep `TODO.md` short and scannable.

## Format

- Use `## Tasks` for clear next actions.
- Keep `TODO.md` limited to clear tasks.
- Ask the user about contradictions, uncertain owners, uncertain dates, and
  schedule conflicts before adding them to `TODO.md`.
- Write tasks as unchecked Markdown checkboxes.
- Start each task with a verb.
- Do not add a `## Questions` section to `TODO.md`.
